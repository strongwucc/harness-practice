# 给 AI 编码助手「立规矩」：Harness Engineering 实践证据仓

> 把大模型接进真实项目，难点从来不在「会不会写代码」，而在「敢不敢信它的产出」。模型是发动机，Harness 是整车：发动机决定性能上限，整车工程决定这个性能能不能安全兑现成生产价值。这个仓库是「整车工程」的个人实践证据：**方法论在知识库里，证据在这里。**

13 年支付/零售业务工程师的个人 Harness 工程体系——一个仓库讲清三件事：

1. **我有一套体系** —— 10 个互相咬合的组件：门禁、失败案例库、AI 行为评测、双 AI 协作约束、分层审查……（见 [COMPONENTS.md](COMPONENTS.md)）
2. **体系处理过真实事故** —— 深案例：测试全绿，事故照发生。契约失真如何骗过测试，见下方「30 秒看懂深案例」
3. **我知道体系的能力边界** —— 证据分级 + 诚实边界声明（见文末「诚实边界」，建议先读）

> **作品边界一句话**：公开案例展示如何用契约 fixture 揭露假绿测试；组件页描述私有项目中使用的 AI 工作约束——具体协作过程不作还原（原因见案例 [EVIDENCE.md](cases/01-cents-vs-yuan/EVIDENCE.md)）。

## 30 秒看懂深案例

这是对一次真实支付事故的机制级重建（历史证据与合成演示逐项分级，见案例内 [EVIDENCE.md](cases/01-cents-vs-yuan/EVIDENCE.md)）：

```
渠道按「分」传金额：item_price = 60，意思是 0.60 元
本方系统按「元」记账：0.60

校验时没统一单位就比较：60 ≠ 0.60
→ 平价订单被误拒（历史记录中受影响范围为当时全部下单请求）

但当时的测试套件全绿。为什么没拦住？
→ 测试用的假数据也是按「元」造的——出卷人和考生犯了同一个错，考卷考不出来

修复后怎么证明不再犯？
→ 假数据严格照渠道真实格式（按分）造。同一组用例，立刻分辨：
   事故版 1/3（唯一「过」的用例是碰巧），修复版 3/3
```

术语速查（后文用到的黑话都在这）：

| 词 | 一句话解释 |
|----|-----------|
| 契约 | 外部系统承诺的数据格式。本案例里：渠道承诺「金额按分传」 |
| mock / fixture | 测试用的假数据。关键差别在输入是否忠实于外部契约：按「元」造 = 和被测代码继承同一个错误假设（同源）；按「分」造 = 忠实于渠道真实格式 |
| 假绿 | 测试全绿但实现是错的——测试给出了虚假的安全感 |
| evals | 失败案例资产化：bug 修完当场固化成「日期/根因/复现/期望」回归条目，修 bug 前必查、修完必固化 |
| Harness | 见开头类比：让强模型稳定兑现生产价值的一整套工程约束 |

## 快速开始（60 秒）

```bash
git clone https://github.com/strongwucc/harness-practice
cd harness-practice/cases/01-cents-vs-yuan
python3 demo.py
```

Python 3.8+ 标准库，零第三方依赖，零 API 成本。输出四幕对照 + 一段事故响应，对照关系如下：

| 幕 | 你会看到 | 说明 |
|----|---------|------|
| [1] 契约层 | item_price=60（分）vs frozen_cost='0.60'（元） | 两边金额事实一致（都是 0.60 元），但单位不同——事故的种子是单位，不是数值 |
| [2] 校验层 | Decimal(60) ≠ Decimal(0.60) → 平价样本被误拒 | 单位没统一就比较，数值恒不等；历史记录中受影响范围为当时全部下单请求 |
| [3] 事故前测试组（元值 mock，合成） | 对事故版 3/3 全绿 | 被测实现是错的，测试却全绿——「同源假绿」实证 |
| [4] 修复后测试组（忠实契约 fixture） | 事故版 1/3（唯一「过」的用例是碰巧），修复版 3/3 | 测试的牙齿来自「输入忠实于外部契约」，不来自断言数量 |
| [5] 事故后的体系响应 | 教训正式命名并在设计中持续引用；同族排查出 4 个同日修复；失败案例当场固化为回归条目 | 体系吃事故的方式：命名 → 引用 → 排查 → 资产化 |

## 诚实边界（先读这个）

- **个人项目级体系**：单人负责的电商/支付系统，非团队平台；「团队内推广」仅指方法论传播过程

- **不声称的**：协作分工的逐步还原（提交署名只能证明参与声明）、修复只用 22 分钟（那是反馈记录到修复提交的时间差）、体系的普遍拦截率（未测量）
- **私有仓库**：生产载体为 Gitee 私有仓库（门禁/evals/ADR 实物），公开内容为脱敏重建与描述
